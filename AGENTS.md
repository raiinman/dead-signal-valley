# Dead Signal Valley

This project uses the [DOX framework](https://github.com/raiinman/dox), adapted from commit `b88194c34ace1a2a3dc01831d36b8a65986a41f5`. Attribution and license are in `docs/dox/`.

## Core contract

AGENTS.md files are binding contracts for their subtrees. Before editing, read this file and every AGENTS.md along the target path, following the Child DOX Index. The nearest document owns local details; children may not weaken DOX. Work products, source materials, assets and records must remain understandable from this chain.

After every meaningful change, review the owning document and update affected scope, ownership, contracts, workflows, inputs, outputs, quality standards and durable user preferences. Refresh affected parent/child indexes and remove stale guidance. Small changes may leave documents unchanged after this review. At closeout, check all changed paths against the chain, run relevant existing checks, and report intentionally unchanged docs and why.

Create a child contract for a durable domain boundary. Use Purpose, Ownership, Local Contracts, Work Guidance, Verification and Child DOX Index sections. Keep contracts concise and current; document stable operating rules rather than task history.

## Project contracts

- This is the current editable playable build. `dist/` contains both source and deployed output. Its GLBs include original PBR textures; no service credentials are required.
- Preserve the separate-item Meshy workflow, original espresso fidelity, measured café doorway/furniture collision, town signals and quality/time controls.
- Production is https://deadsignal.studio on existing cPanel hosting. Run the checks before publishing only `dist/`. Preserve hosting configuration and a private rollback copy.
- Earlier builds and Blender backups stay outside this repository. Include every asset required for the current runtime and its tests.

## User preferences

- Make authorized maintenance decisions autonomously. User messages during work steer the active task.
- Keep updates brief and outcome first. Use punctuation other than em dashes.
- After an asynchronous form, wait at least 30 seconds unless answered sooner. Elapsed time is not approval.
- Subagents and Meshy purchases are authorized for this project. Generate individual items rather than a whole detailed building.

## Documentation lookup

Use Context7 for library, framework, SDK, API, CLI or cloud-specific documentation. Resolve the library ID first unless an exact `/org/project` ID was supplied, then query relevant official documentation by concept. General scripts, business logic, refactoring and review do not require Context7.

## Child DOX Index

- `dist/AGENTS.md`: editable web runtime and Meshy asset contracts.
- `docs/AGENTS.md`: development, provenance, deployment and DOX attribution.
- `tools/AGENTS.md`: local server, manifest checks and cPanel publishing.

Root owns package scripts, tests, browser checks and evidence. Evidence captures the tested build and source hash baselines. Third-party upstream documents are reference material, not overrides of this contract.
