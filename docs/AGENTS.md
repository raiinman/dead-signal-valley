# Documentation

## Purpose

Enable a clean checkout to be run, edited and deployed by another person or AI agent.

## Ownership

DEVELOPMENT.md owns architecture and workflow; DEPLOYMENT.md owns hosting and rollback; ASSETS.md owns model provenance. `dox/` holds upstream framework reference and license. `runtime-manifest.json` is generated from current deployed files.

## Local Contracts

Describe tested behavior accurately, preserve source attribution and keep secrets out of documentation. Upstream framework text is retained as a reference, with the root AGENTS.md as the active adaptation.

## Work Guidance

Use portable repository-relative links and runnable commands. Record deployment identity without account session tokens or credentials.

## Verification

Check links and commands against the checkout; verify the runtime manifest using its package script.
